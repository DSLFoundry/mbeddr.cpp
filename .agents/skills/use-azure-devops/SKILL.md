description: Uses explicitly requested Azure DevOps capabilities with scoped authentication and verified outcomes.

This is optional; no Azure service is configured by this skill. Establish the
user's intended organization/project/repository from explicit context or a
verified remote, not private defaults copied from elsewhere. Discover tool
schemas or installed `az devops` help and test existing access with a bounded
read. Never print tokens or change global CLI defaults to make a task work.

For lists, follow pagination and report partial results. For requested writes,
retrieve the record and valid fields/states, check for duplicates and concurrent
updates, apply only authorized changes, then re-read the affected record or
relationship. Queued execution is not successful execution. Stable IDs and
actual outcomes belong in task reports, not learned public profile content.

Do not install extensions, trigger pipelines, deploy, merge or delete records
without explicit authorization. Use the hosting platform appropriate to the
request; never replace GitHub operations with Azure operations. Apply
`.agents/SELF-LEARNING.md` to public-safe reusable findings only.
